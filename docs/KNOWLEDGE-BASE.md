# RSMChords Knowledge Base

This guide explains how RSM Church Music Ministry can use the main RSMChords features when preparing services, rehearsals, and ministry resources.

## Core concepts

| Feature | Purpose |
|---|---|
| Song library | Stores worship songs, lyrics, chords, arrangements, attachments, and rehearsal notes. |
| Songlist | Groups related songs without defining a service order, such as communion songs or Christmas repertoire. |
| Setlist | Defines the ordered songs for a service, rehearsal, or ministry event. |
| Technical Rider | Documents the audio, equipment, monitor, and stage setup required by the worship team. |
| Press Kit / Ministry Profile | Creates a shareable ministry information page containing text, photos, videos, and links. |

## Technical Riders

### What is a Technical Rider?

A Technical Rider is a reusable document that tells the sound and production team how the worship team should be set up. It keeps the worship leader, musicians, sound engineer, and volunteers working from the same technical plan.

A rider is separate from a setlist:

- A **setlist** describes which songs will be used and their order.
- A **technical rider** describes how the people, instruments, microphones, monitors, and stage should be configured.

### Suggested riders for RSM Church

- RSM Sunday Worship Setup
- Youth Service Setup
- Acoustic Worship Setup
- Christmas Program Setup
- Outdoor Service Setup

If the same arrangement is used most weeks, maintain one primary rider and update it whenever the team or equipment changes.

### Information to include

- Worship-team member or source assigned to each audio input
- Microphone and DI-box requirements
- Instruments, amplifiers, and playback devices
- Mixer channel assignments
- Floor-monitor or in-ear-monitor requirements
- Stage positions and stage plot
- Power, cable, and equipment requirements
- Setup, soundcheck, accessibility, and other technical notes

### Example input list

| Channel | Source | Equipment | Notes |
|---|---|---|---|
| 1 | Worship leader | Wireless vocal microphone | Center stage |
| 2 | Acoustic guitar | DI box | Include in monitor 1 |
| 3 | Keyboard left | Direct input | Stereo pair |
| 4 | Keyboard right | Direct input | Stereo pair |
| 5 | Bass guitar | DI box | Include in in-ear mix |
| 6–10 | Drum kit | Drum microphones | Drum shield if required |

### Recommended workflow

1. Select the RSM Music Ministry workspace.
2. Expand **Technical Riders** in the sidebar.
3. Select the plus button and give the rider a descriptive name.
4. Add every required input, instrument, microphone, and monitor.
5. Arrange the stage plot to match the physical platform.
6. Add setup and soundcheck notes.
7. Review the rider with the worship leader and sound-team leader.
8. Update it whenever equipment or personnel changes.

## Press Kits and Ministry Profiles

### What is a Press Kit?

A traditional Press Kit is a public-facing page used by a music group to share its biography, photos, videos, links, and promotional material. In RSMChords, RSM Church can use the same feature as a **Ministry Profile** or **Ministry Media Page**.

Press Kits are optional. Ignoring this feature does not affect the song library, setlists, rehearsals, or Technical Riders.

### Church-focused uses

- RSM Music Ministry Profile
- Worship Conference Media Page
- Christmas Concert Information
- Youth Worship Ministry Profile
- Visiting Worship Team Information
- Special ministry event page

### Information to include

- Ministry or worship-team introduction
- Church and ministry description
- Worship-team photographs
- Approved church or ministry logo
- Ministry vision, mission, or testimony
- YouTube worship videos or livestream links
- Church website and approved social-media links
- Public ministry contact information
- Event or conference details
- Approved downloadable media resources

### Recommended workflow

1. Select the appropriate ministry workspace.
2. Expand **Press Kits** in the sidebar.
3. Select the plus button and create a clearly named profile.
4. Add approved text, photographs, videos, and links.
5. Ask a ministry leader to review the content before enabling public sharing.
6. Copy the public share link only after the page is ready.
7. Revoke or disable sharing when the page is no longer needed.

### Public-sharing safety

A publicly shared Ministry Profile may be accessible without an RSMChords account. Do not include:

- Private telephone numbers or personal email addresses
- Home addresses
- Children's personal information
- Internal schedules, door codes, or security procedures
- Copyrighted photographs or recordings without permission
- Any information intended only for church staff or ministry members

Use a church-approved public email address and obtain permission before publishing identifiable photographs, recordings, or testimonies.

## Quick comparison

| Question | Use this feature |
|---|---|
| Which songs will we use this Sunday, and in what order? | Setlist |
| Which songs belong to a particular theme or season? | Songlist |
| Which microphone, input, monitor, and stage position does everyone need? | Technical Rider |
| What ministry information and approved media should we share publicly? | Press Kit / Ministry Profile |

## RSM Church operating recommendations

- Give accounts only to authorized ministry members.
- Use viewer access when someone does not need to edit resources.
- Review public links before sharing them outside the church.
- Keep one current Technical Rider for each standard worship-team configuration.
- Use clear names containing the ministry, service, or event name.
- Back up the PostgreSQL database and uploaded attachments regularly.
- Remove access promptly when someone no longer serves in the ministry.
